# Sagar Rathod Portfolio

A dark, editorial-style developer portfolio for Sagar Rathod, a Computer Engineering student at Vidyalankar Institute of Technology focused on AI/ML, Computer Vision, Data Analytics, and Full-Stack Development.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Features

- Responsive single-page portfolio with sticky navigation and mobile menu
- Hero section with terminal-inspired visual
- About, skills, project, journey, contact, and footer sections
- Structured project and skill data in `src/data`
- Synthetic project visuals for document intelligence, port analytics, graph analysis, and computer vision
- Native form validation and reduced-motion support
- No backend and no fabricated metrics, achievements, employment, or database access

## Projects

- LexClarity: AI / NLP / LegalTech
- Port Operations Intelligence: Data Analytics / Logistics
- Criminal Network Analysis System: Investigation Support / Graph Analytics
- CONFIDENTIAL DOSSIER: Python / Computer Vision / Face Recognition
